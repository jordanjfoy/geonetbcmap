## App Overview

**geonetbcmap** is a **React + TypeScript web mapping application** being built to recreate the MASCOT map for integration with the GeoNetBC database.
### Core Purpose

It's a geospatial data visualization and markup tool that allows users to:

- View and interact with geographic data (maps)
- Draw features on the map (points, lines, polygons, circles)
- Manage base layers and data layers
- Query and navigate the map

### Technology Stack

- **Frontend**: React 18 + TypeScript
- **Mapping**: OpenLayers 10 (professional GIS mapping library)
- **Styling**: MapBox style support via `ol-mapbox-style`
- **UI Framework**: Custom ribbon interface (similar to Office/ArcGIS)
- **Build**: Webpack with development server
